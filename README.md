# Автотесты приложения «Делим счёт»

Набор UI-автотестов на Playwright для учебного pet-проекта - приложения для разделения счёта в кафе [«Делим счёт»](https://merz1ota.github.io/split_bill_cafe/). Проект показывает подход к проверке пользовательских сценариев.

## Проверяемое приложение:

Ссылка на GitHub Pages: https://merz1ota.github.io/split_bill_cafe/

Ссылка на исходный код https://github.com/Merz1ota/split_bill_cafe

## Что и как проверяется

Проверки разделены на две категории:

- **Smoke** - один главный критический путь: создать участников и общую позицию, затем убедиться, что приложение рассчитало долг. Он отвечает на вопрос, работает ли основной пользовательский сценарий.
- **Regression** - детальные проверки пользователей, продуктов и результатов расчёта. Реализованы тесты границы цены, округление и отдельное воспроизведение известного дефекта. Регрессионные тесты помечены как `@regression`.

### Границы и округление значений сумм

- Для цены продукта проверяются `0` и `-0.01` как недопустимые значения, а `0.01` - как допустимое минимальное положительное значение.
- В расчёте проверяются результаты `10.09 / 2` и `10.10 / 2` для проверки значения по обе стороны границы округления до десятых.
- Отдельные проверки покрывают разделение общей позиции между участниками и взаимное погашение долгов.

### Дефект

`BUG-001`: на странице результатов приложение отображает строку с нулевым долгом.
Дефект воспроизводится отдельным тестом в `tests/regression/results/results.spec.ts`. Тест помечен `test.fail` как ожидаемо падающий

Исправление ошибки относится к коду приложения и не входит в репозиторий автотестов.

## Запуск

Требуется Node.js 24 или новее.

```bash
npm ci
npx playwright install chromium
npm run typecheck
npm test
```

`npm test` - Полный набор: Smoke и Regression (14 тестов, включая ожидаемо падающий тест известного дефекта)

`npm run test:critical` - Критический Smoke

`npm run test:regression` - Регрессионные проверк

`npm run typecheck` - Проверка типов TypeScript без генерации

`npx playwright show-report` - HTML-отчёт

## CI

GitHub Actions устанавливает зависимости и Chromium, проверяет типы и запускает полный набор командой `npm test` на `push`, `pull_request` и вручную

## Структура

```text
.github/workflows/playwright.yml   # GitHub Actions: типы и полный набор на pull request
tests/
  smoke/                           # критический пользовательский путь (@smoke, @critical)
  regression/
    users/                         # сценарии участников (@regression)
    products/                      # сценарии продуктов и границ цены (@regression)
    results/                       # расчёт, округление и BUG-001 (@regression)
pages/                             # Page Object классы экранов
utils/                             # общие типы и сценарии
```

## Технологии

- TypeScript и Playwright Test.
- Chromium и опубликованная версия приложения на GitHub Pages.
- Page Object Model: локаторы и действия экранов вынесены в отдельные классы.
- GitHub Actions для проверки типов и запуска тестов на pull request.
